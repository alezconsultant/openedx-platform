# Team-governed version pins.
#
# Unlike the rest of [tool.edx_lint].uv_constraints (compatibility pins anyone can
# adjust as part of routine dependency work), every package listed here is pinned
# because its owning team wants to control exactly when it moves, rather than having
# it bumped automatically by `make upgrade`/`uv lock --upgrade`. Split into its own
# file (rather than pyproject.toml's much larger, frequently-touched uv_constraints
# array) so CODEOWNERS can gate changes to just these specific pins -- see
# .github/CODEOWNERS.
#
# Format: one `name==version` constraint per line. Merged into
# [tool.uv].constraint-dependencies by `make compile-requirements` (via
# scripts/merge_team_constraints.py), after `edx_lint write_uv_constraints` and
# before `uv lock` -- so an entry here always wins over anything write_uv_constraints
# would otherwise produce for the same package. To bump one of these, either edit
# this file directly, or run the "Upgrade one Python dependency" GitHub Actions
# workflow (scripts/update_uv_constraint_version.py checks this file first).
